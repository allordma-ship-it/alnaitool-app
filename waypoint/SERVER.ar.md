# إعداد خادم ونيس على الإنترنت

بعد هذه الخطوات يصبح لديك خادم يعمل 24 ساعة بعنوان `https://...`، يستخدمه كل مستخدمي التطبيق في سوريا.

**ما تحتاجه:** بطاقة مصرفية (من حسابك في ألمانيا مثلاً)، وحوالي 30 دقيقة.
**التكلفة:** حوالي 5 يورو شهرياً. اسم النطاق (الدومين) اختياري.

---

## 1. استئجار الخادم (VPS)

مثال بشركة **Hetzner Cloud** الألمانية، وهي رخيصة وموثوقة. أي شركة أخرى تقدّم Ubuntu تصلح أيضاً.

1. سجّل في https://console.hetzner.cloud ثم اضغط **Add Server**.
2. اختر:
   - **Location:** Nuremberg أو Falkenstein أو Helsinki.
   - **Image:** Ubuntu 24.04.
   - **Type:** CX22 (2 معالج، 4 GB ذاكرة)، وهو كافٍ للبداية.
   - **SSH key:** يُفضَّل إضافته. إن لم تعرفه، ستصلك كلمة مرور root بالبريد الإلكتروني.
3. اضغط **Create** واحفظ **عنوان IP** الخاص بالخادم، مثل `203.0.113.7`.

> ⚠ قبل الإطلاق الرسمي: جرّب فتح عنوان الخادم من هاتف داخل سوريا للتأكد أن الاتصال يعمل. بعض الشركات تحجب الدخول من دول معيّنة.

---

## 2. الدخول إلى الخادم

من كمبيوترك افتح **PowerShell** (في Windows) أو **Terminal** (في Mac) واكتب:

```bash
ssh root@203.0.113.7
```

ضع عنوان IP الخاص بخادمك بدل الرقم في المثال. اكتب `yes` ثم كلمة المرور.

---

## 3. تنزيل ونيس وتشغيله

انسخ هذه الأوامر كما هي:

```bash
apt-get update && apt-get install -y git
git clone -b ccr-f08a480e-luxg2r https://github.com/allordma-ship-it/alnaitool-app.git
cd alnaitool-app/waypoint
sudo ./deploy/setup-server.sh
```

- إذا كان المستودع خاصاً سيطلب GitHub اسم المستخدم وكلمة مرور. استخدم **رمز وصول (Token)** بدل كلمة المرور. تنشئه من GitHub: Settings ← Developer settings ← Personal access tokens، بصلاحية قراءة فقط لهذا المستودع.
- السكربت يفعل كل شيء تلقائياً:
  - يثبّت Docker.
  - يفعّل الجدار الناري.
  - ينشئ كلمات مرور عشوائية.
  - يحمّل خريطة طرق سوريا.
  - يفعّل HTTPS.
  - يأخذ نسخة احتياطية يومية لقاعدة البيانات.
- في المرة الأولى يستغرق 5 إلى 15 دقيقة. في النهاية يطبع عنوان الخادم، مثل:

```
✔ ونيس يعمل!
      https://203-0-113-7.sslip.io
```

هذا العنوان مجاني ويعمل مباشرة مع HTTPS، دون شراء نطاق.

---

## 4. ربط التطبيق بالخادم

- **الطريقة الأسهل:** في التطبيق اضغط أيقونة الخادم 🖧 في شاشة الدخول، أو اذهب إلى «حسابي ← عنوان الخادم». اكتب العنوان الذي ظهر، ثم «اختبار الاتصال» ثم «حفظ».
- **الطريقة الأفضل للنشر:** اجعل العنوان مدمجاً في التطبيق، فلا يحتاج المستخدمون لكتابة شيء:
  1. في GitHub افتح Settings ← Secrets and variables ← Actions ← تبويب **Variables**.
  2. أضف متغيراً باسم `WANEES_API_URL` وقيمته عنوان خادمك، مثل `https://203-0-113-7.sslip.io`.
  3. شغّل بناء التطبيق من جديد، واستخدم ملف **wanees-release-apk**.

---

## 5. نطاق خاص (اختياري)

إذا اشتريت نطاقاً، مثل `wanees.app`:
1. في إعدادات النطاق أضف سجل **A** باسم `api` يشير إلى عنوان IP الخاص بخادمك.
2. على الخادم نفّذ:
   ```bash
   cd ~/alnaitool-app/waypoint
   sudo ./deploy/setup-server.sh api.wanees.app
   ```
