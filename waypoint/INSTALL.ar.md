# تثبيت ونيس على الموبايل

يتكوّن ونيس من جزأين:

1. **الخادم (السيرفر):** يحفظ الحسابات والرحلات والحجوزات. يجب أن يعمل على جهاز يصل إليه الهاتف.
2. **التطبيق:** ملف APK يُثبَّت على هواتف أندرويد.

---

## أولاً: تشغيل الخادم

### للتجربة على كمبيوترك (نفس شبكة الواي فاي)

1. ثبّت [Docker Desktop](https://www.docker.com/products/docker-desktop/) وشغّله.
2. افتح الطرفية (Terminal) في مجلد `waypoint` ونفّذ:
   ```bash
   make up
   ```
   في المرة الأولى يحمّل الخادم خريطة طرق سوريا ويجهّزها، وقد يستغرق ذلك بضع دقائق.
3. اعرف عنوان كمبيوترك على الشبكة:
   - **Windows:** نفّذ الأمر `ipconfig` وابحث عن «IPv4 Address»، مثل `192.168.1.10`.
   - **Mac:** افتح «إعدادات النظام ← الشبكة»، أو نفّذ الأمر `ipconfig getifaddr en0`.
4. عنوان الخادم يصبح: `http://192.168.1.10:8080`، مع وضع رقم جهازك بدل الرقم في المثال.

### للاستخدام الحقيقي (مستخدمون في كل سوريا)

تحتاج خادماً على الإنترنت (VPS) ونطاقاً (دومين) مع شهادة HTTPS، مثل `https://api.wanees.sy`. شغّل عليه الأمر نفسه `make up` خلف وكيل عكسي (مثل Caddy أو Nginx) يوفّر HTTPS.

## ثانياً: الحصول على ملف APK

يبني GitHub التطبيق تلقائياً عند كل تعديل:

1. افتح المستودع على GitHub ثم تبويب **Actions**.
2. اختر **Wanees Android APK** ثم آخر تشغيل ناجح (علامة ✓ خضراء).
3. في أسفل الصفحة، تحت **Artifacts**، ستجد ملفين مضغوطين (ZIP):
   - `wanees-test-apk`: للتجربة، ويعمل مع خادم على كمبيوترك (`http://...`).
   - `wanees-release-apk`: النسخة النهائية، وتعمل فقط مع خادم `https://...`.

لبناء نسخة بعنوان خادم معيّن: افتح **Actions ← Wanees Android APK ← Run workflow**، واكتب العنوان في الحقل.

---

## ثالثاً: التثبيت على هاتف أندرويد

1. انقل ملف APK إلى الهاتف، عبر واتساب أو تلغرام أو كابل USB أو Google Drive.
2. افتح الملف من الهاتف.
3. إذا ظهرت رسالة «تثبيت تطبيقات غير معروفة»، اضغط **الإعدادات** وفعّل **السماح من هذا المصدر**، ثم ارجع واضغط **تثبيت**.
4. افتح **ونيس**. في شاشة الدخول اضغط أيقونة الخادم (🖧) في الأعلى:
   - اكتب عنوان الخادم، مثل `http://192.168.1.10:8080`.
   - اضغط **اختبار الاتصال**. يجب أن تظهر رسالة «تم الاتصال بالخادم بنجاح».
   - اضغط **حفظ**.
5. أنشئ حساباً وابدأ الاستخدام.

> ملاحظة: عند تثبيت نسخة جديدة فوق نسخة قديمة، قد يرفض الهاتف التحديث لأن كل بناء يُوقَّع بمفتاح مختلف. في هذه الحالة احذف القديمة أولاً. للنشر الرسمي يلزم مفتاح توقيع ثابت.

## آيفون (iOS)

يتطلب جهاز Mac مع Xcode، وحساب Apple Developer (99 دولاراً سنوياً). التوزيع يكون عبر TestFlight أو App Store:
```bash
make mobile-bootstrap
cd mobile && flutter build ipa
```
